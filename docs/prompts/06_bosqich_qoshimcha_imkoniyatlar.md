# 6-BOSQICH (ixtiyoriy): Qo'shimcha imkoniyatlar

(Avval `00_umumiy_kontekst.md`, keyin shuni. 1-5 bosqichlar ishlab turgandan keyin. Hammasini birdan emas, birma-bir qil va har biridan keyin menga ko'rsat.)

1. **SMS va Telegram bildirishnomalar:** buyurtma tasdiqlandi, haydovchi yo'lga chiqdi, yetkazildi (Eskiz.uz SMS API va Telegram bot).
2. **Hisobotlar:** kunlik/oylik savdo hajmi, eng faol do'konlar, mahsulot bo'yicha talab, qarzdorlar ro'yxati; Excel/PDF eksport.
3. **Doimiy takroriy buyurtmalar:** masalan har dushanba 10 quti; avtomatik buyurtma yaratish.
4. **Ombor qoldig'i nazorati:** mahsulot tugab qolsa buyurtmada ogohlantirish.
5. **Yetkazib berish isboti:** imzo/rasm, GPS tasdig'i.
6. **Yangi kompaniya qo'shish:** super admin panelida kodsiz (Fanta, Pepsi, shirinliklar), brend rangi va logotipi bilan; bir soatdan kam vaqtda ishga tushishi tekshirilsin.
7. **Ishlab chiqarishga chiqarish (deploy):** VPS, HTTPS, avtomatik zaxira, monitoring, xatolik loglari, qo'llanma.

Har bir band uchun: qisqa reja → amalga oshirish → testlar → qanday ishlatilishi.
